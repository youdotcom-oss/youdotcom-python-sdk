# Freshness

Specifies the freshness of the results to return.

## Example Usage

```python
from youdotcom.models import Freshness

value = Freshness.DAY
```


## Values

| Name    | Value   |
| ------- | ------- |
| `DAY`   | day     |
| `WEEK`  | week    |
| `MONTH` | month   |
| `YEAR`  | year    |
