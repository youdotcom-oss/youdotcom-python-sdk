## Notes

`page_age` is `Union[datetime, str, None]` — an ISO 8601 value parses to a
`datetime`, any other value is returned verbatim. Narrow with `isinstance`
before using it as a datetime; see
[WebResult](webresult.md#page_age-may-be-a-string) for the full table.
