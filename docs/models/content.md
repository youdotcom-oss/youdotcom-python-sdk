# Content

The comprehensive response with inline citations. When content_type is "text", this is a Markdown string with numbered citations that reference the items in the sources array. When content_type is "object", this is a structured JSON object matching the requested output_schema.


## Supported Types

### `str`

```python
value: str = /* values here */
```

### `Dict[str, Any]`

```python
value: Dict[str, Any] = /* values here */
```
