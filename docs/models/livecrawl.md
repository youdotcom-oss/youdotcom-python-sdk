# LiveCrawl

Indicates which section(s) of search results to livecrawl and return full page content.

## Example Usage

```python
from youdotcom.models import LiveCrawl

value = LiveCrawl.WEB
```


## Values

| Name   | Value  |
| ------ | ------ |
| `WEB`  | web    |
| `NEWS` | news   |
| `ALL`  | all    |
